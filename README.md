# Steal an Egg

Repository de développement du jeu Roblox **Steal an Egg**.

## Objectif

Conserver l'intégralité du projet, son historique, ses scripts, sa documentation, ses builds Roblox et les informations nécessaires à la maintenance du jeu.

## Structure

- `roblox/original/` : copie originale du pack acheté, à ne jamais modifier.
- `roblox/builds/` : builds jouables générés.
- `src/` : sources Luau extraites et versionnées.
- `localization/` : traductions EN/FR.
- `assets/` : inventaires des AssetIds et ressources externes.
- `docs/` : architecture, économie, remotes, sécurité, publication.
- `audit/` : inventaires techniques et problèmes connus.

## État actuel

Le projet contient 89 sources Luau :
- 29 Scripts serveur
- 34 LocalScripts
- 26 ModuleScripts

Le place analysé contient 86 408 instances et 107 classes Roblox.

## Langues

- English (fallback/source)
- Français

La langue affichée suit automatiquement la locale Roblox du joueur.

## Important

Ce dépôt contient un pack Roblox acheté. Ne pas republier ou redistribuer le contenu sans vérifier les droits de licence associés.

Les secrets (cookies Roblox, tokens, clés API, credentials) ne doivent jamais être commités.
