# Localization

Localization is designed to keep gameplay identifiers stable while translating player-visible text.

Current languages:
- English: default/fallback
- French: selected from the player's Roblox locale

The localization patches also handle dynamically-created UI, prompts and many world/HUD labels.

Do not translate internal keys used by:
- DataStores
- RemoteEvents
- Attributes
- persisted item identifiers
- service/script names
